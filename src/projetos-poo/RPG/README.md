# Ideias para o projeto
    - Ter as seguintes classes Maestria,Inventario,Monstros , Sistema de Batalha
    - Maestria vai ter seguintes funções:
        ° Criar uma maestria/classe , definindo seu nome e ter opção de randomizar os seus atributos ou não
        ° Salvar as maestrias
        ° Exibir todas as maestrias salvas no sistema
        ° Carregar os dados para não ter dados duplicados
        ° Editar alguma variavel que não gostou
        ° Remover maestria
    
    - Inventario terá as seguintes funções:
        ° Dizer se tem algum item no inventario ou não
        ° Exbir moedas

    - Monstros terá as seguintes funções:
        ° Criar os mobs/monstros
        ° Salvar os mobs em arquivo json
        ° Listar todos os mobs
        ° Definir o que mob pode dropar ex(mob cachorro dropou 5 moedas)
    
    - Sistema de Batalhas
        ° Batalhas entre os jogadores contra os mobs
        ° Regra de dano igual ao D&D , calcular o dano atravéz de roleta de dados de 0 a 20
