# API RESTful de Gestão de Tarefas (To-Do API)
O que é: Uma API completa para gerenciamento de tarefas (CRUD) com suporte a múltiplos usuários, autenticação via token (JWT) e documentação automática.

    - Tecnologias sugeridas: FastAPI ou Flask, SQLAlchemy (ORM), SQLite ou MySQL, Pydantic.

    - O que você aprende: Modelagem de banco de dados relacional, controle de acesso e segurança, validação rigorosa de dados de entrada e criação de documentação interativa (Swagger/OpenAPI).
